# Signal — dashboard ข่าวที่ตรวจสอบและภัยหลอกลวง

ต้นแบบภาษาไทยจากข้อมูลจริง ใช้ `weekly_panel` เป็นตารางหลัก กราฟเส้นและกราฟแท่ง ไม่มี scatter plot ใช้งานในเครื่องได้โดยไม่ติดตั้งแพ็กเกจเพิ่มเติม และไม่ต้องมีอินเทอร์เน็ตเพื่อโหลดกราฟหรือฟอนต์

## เปิดดูต้นแบบ

เปิด `prototype/index.html` ด้วย Chrome/Edge ได้ทันที (ใช้ไฟล์ JS ข้อมูลที่เตรียมไว้ ไม่ต้อง fetch)

หรือรันจากโฟลเดอร์โปรเจค:

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

แล้วเปิด http://127.0.0.1:8766/prototype/

ใน Windows สามารถคลิกขวา `prototype/index.html` แล้วเลือก Open with → Chrome/Edge ได้

## หน้าและคำถาม

1. **ภาพรวมและคดี** — คดีมากกับเสียหายหนักเกิดพร้อมกันไหม? แสดงกราฟเส้นสามหน่วยแยกแผง อันดับสัปดาห์ และรายละเอียดข่าวเมื่อเลือกสัปดาห์
2. **ข่าวที่ถูกตรวจสอบ** — อันดับหมวดตามจำนวนต่างจากอันดับตามสัดส่วนไหม? แสดงกราฟสองชุดและผลตัดสินรายเดือน
3. **บริบทความเสี่ยง AI** — ข้อมูลเท็จอยู่ตรงไหนเมื่อเทียบหมวดอื่นในฐาน AIID? มีตัวกรองปีของตัวเองและกรณีศึกษาต้นทาง
4. **ที่มาและคุณภาพข้อมูล** — วิธีเชื่อม ช่วงผิดปกติ ข้อมูลขาด สูตร และดาวน์โหลด CSV

หน้าหลักเริ่มต้นช่วง 9 พ.ย. 2025–24 ต.ค. 2026 (วันเริ่มสัปดาห์สุดท้าย 18 ต.ค.) แยกช่วงยอดผิดปกติและช่วง 8 วันออกจากคดีโดยค่าเริ่มต้น ข่าว AFNC ในช่วงนั้นยังแสดงครบ ตัวกรองนี้ไม่เปลี่ยนข้อมูลต้นฉบับ

## เตรียมข้อมูลใหม่

ใช้ Python 3.10 ขึ้นไป standard library เท่านั้น:

```powershell
python scripts/prepare_data.py
python scripts/validate_data.py
```

สคริปต์เลือก AIID snapshot วันที่ล่าสุดที่มีจริงใน `dataset/` ไม่รวม snapshot ซ้ำกัน หากต้องการตรึงฉบับสำหรับรายงานให้อ้างอิงชื่อไฟล์และ SHA-256 ใน `data/processed/quality_report.json`

## โครงสร้าง

```text
dataset/                  ข้อมูลต้นฉบับ ไม่แก้ไข
scripts/prepare_data.py    ทำความสะอาด เชื่อม และตรวจยอด
scripts/validate_data.py   ตรวจผลลัพธ์เทียบข้อมูลดิบ
data/processed/            CSV สะอาดและรายงานคุณภาพ
prototype/                เว็บ HTML/CSS/JavaScript พร้อมข้อมูลในเครื่อง
docs/data_methodology.md  วิธีนับ การเชื่อม และข้อจำกัด
```

## ขอบเขต

ใช้ AFNC + ACSC + AIID รวมสามแหล่ง AFNC และ ACSC เชื่อมรายสัปดาห์ผ่าน weekly_panel ส่วน AIID เป็นบริบทประกอบแยก ไม่มีคีย์จับคู่กับคดีไทย การแสดงใน dashboard เดียวกันไม่ใช่การยืนยันความสัมพันธ์ระดับเหตุการณ์

รายละเอียดการทำความสะอาดและสูตรอยู่ใน [docs/data_methodology.md](docs/data_methodology.md)
