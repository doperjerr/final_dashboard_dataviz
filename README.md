อ่านทิศทางคำถาม คอลัมน์ และการเชื่อมฉบับล่าสุดที่ [docs/dashboard_direction.md](docs/dashboard_direction.md)

## เปิดแดชบอร์ด

เปิด `prototype/index.html` ด้วย Chrome/Edge ได้ทันที (ใช้ไฟล์ JS ข้อมูลที่เตรียมไว้ ไม่ต้อง fetch)

หรือรันจากโฟลเดอร์โปรเจค:

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

แล้วเปิด http://127.0.0.1:8766/prototype/

ใน Windows สามารถคลิกขวา `prototype/index.html` แล้วเลือก Open with → Chrome/Edge ได้

## หน้าและคำถาม

มีเพียง **3 แท็บ**:

1. **AI ก่อปัญหาอะไร?** — ภาพรวมรายเดือน → หมวดความเสี่ยงและเจตนา → เลือกเดือนเพื่ออ่านช่วงสัปดาห์และเหตุการณ์จริง
2. **เจาะเรื่องข้อมูลเท็จ** — AIID หมวด Misinformation ในช่วงเดือน/ประเทศเดียวกับแท็บแรก → เจตนาและกรณีศึกษา → บริบทการหักล้าง EUvsDisinfo ซึ่งมีขอบเขตแยกชัดเจน
3. **เสรีภาพอินเทอร์เน็ตโลก** — แผนที่คะแนนปีปลายช่วง → แนวโน้มประเทศ/กลุ่มประเทศเดิม → คะแนนองค์ประกอบ ใช้ตัวกรองปี เพราะไม่มีข้อมูลรายเดือน

วิธีนับและดาวน์โหลดข้อมูลอยู่ในรายละเอียดพับได้ภายในแต่ละแท็บ ไม่เพิ่มแท็บคุณภาพข้อมูล ไม่มีหน้าข่าว/คดีไทยในแดชบอร์ดปัจจุบัน แต่ไฟล์ที่เตรียมไว้ยังคงอยู่

แท็บ 1–2 เริ่มต้น ม.ค. 2020–ต.ค. 2026 เลือกเดือนเริ่ม–สิ้นสุดและประเทศร่วมกันได้ ไม่มีตัวกรองรายวัน หมวดความเสี่ยงใช้เฉพาะแท็บ 1 ส่วนแท็บ 2 ล็อกเป็น Misinformation โดยอธิบายไว้ EUvsDisinfo ใช้เฉพาะช่วงเดือนที่ทับซ้อนข้อมูลของฐาน ไม่รับตัวกรองประเทศ AIID และไม่เติมศูนย์นอกขอบเขตฐาน

ตารางสัปดาห์อาทิตย์–เสาร์นับเฉพาะวันที่อยู่ในเดือนที่เลือก สัปดาห์คร่อมเดือนจึงไม่ทำให้ยอดนับซ้ำ คะแนนเสรีภาพยังคงเป็นรายปี ไม่สร้างคะแนนรายเดือนขึ้นเอง

## การเชื่อมกราฟและตัวกรอง

- ยึด 5 คำถาม: แนวโน้ม AI → ประเภทความเสี่ยง → สัดส่วน/ลักษณะข้อมูลเท็จ → การหักล้าง EUvsDisinfo → เสรีภาพประเทศ
- คลิกจุดเดือนเพื่อกรองการ์ด กราฟ และตาราง AIID พร้อมกัน มีปุ่มกลับช่วงเดือนก่อนคลิก
- คลิกแท่งหมวดความเสี่ยงเพื่อกรองแท็บ 1 และคลิกแท่งเจตนาเพื่อกรองส่วน AIID ของแท็บ 1–2
- EUvsDisinfo รับเฉพาะช่วงเดือนที่มีข้อมูล ไม่รับประเทศหรือเจตนาจาก AIID
- เลือกประเทศบนแผนที่แล้วคะแนน แนวโน้ม และองค์ประกอบเปลี่ยนตามกัน คลิกปีในเส้นคะแนนเพื่อเปลี่ยนปีบนแผนที่
- มีปุ่มล้างตัวกรองและดาวน์โหลดเฉพาะข้อมูล AIID ตามตัวกรองปัจจุบัน
- URL จำตัวกรอง เปิดหรือโหลดลิงก์เดิมเพื่อกลับมุมมองเดิมได้

## เตรียมข้อมูลใหม่

ใช้ Python 3.10 ขึ้นไป standard library เท่านั้น:

```powershell
python scripts/prepare_data.py
python scripts/prepare_context.py
python scripts/validate_data.py
node scripts/check_monthly.cjs
```

ตรึง AIID ฉบับ 20261026 ตามข้อกำหนด ไม่รวม snapshot ซ้ำกัน อ้างอิงชื่อไฟล์และ SHA-256 ใน `data/processed/quality_report.json` และ `prototype/context.js` สำหรับแหล่งบริบท

## โครงสร้าง

```text
dataset/                  ข้อมูลต้นฉบับ ไม่แก้ไข
scripts/prepare_data.py    ทำความสะอาด เชื่อม และตรวจยอด
scripts/prepare_context.py เตรียมคะแนนประเทศ การหักล้าง และ left join คะแนนกับ AIID
scripts/validate_data.py   ตรวจผลลัพธ์เทียบข้อมูลดิบ
data/processed/            CSV สะอาดและรายงานคุณภาพ
prototype/                เว็บ HTML/CSS/JavaScript พร้อมข้อมูลในเครื่อง
docs/data_methodology.md  วิธีนับ การเชื่อม และข้อจำกัด
```
