# ทิศทางฉบับปรับแก้: AIID เป็นตารางหลัก

## โครงสร้างใช้งานล่าสุด: 3 แท็บเท่านั้น

1. **AI ก่อปัญหาอะไร?** ใช้ AIID เป็นหลัก เรียงคำอธิบายจากแนวโน้มรายเดือน → หมวดความเสี่ยงและเจตนา → เลือกเดือนลงรายละเอียดสัปดาห์ → อ่านเหตุการณ์จริง
2. **เจาะเรื่องข้อมูลเท็จ** ใช้ช่วงเดือนและประเทศร่วมกับแท็บแรก กรอง AIID เฉพาะ Misinformation แล้วดูแนวโน้ม เจตนา และกรณีศึกษา จากนั้นขยายบริบท EUvsDisinfo ในส่วนที่ระบุแยก ไม่รวมยอดหรืออ้างว่าเกิดจาก AI
3. **เสรีภาพอินเทอร์เน็ตโลก** ดูแผนที่ปีปลายช่วง แล้วอ่านแนวโน้มคะแนนและองค์ประกอบของประเทศเดียวกัน เป็นบริบทเสรีภาพ ไม่ใช่ตัวแปรพิสูจน์เหตุและผล

ตัวกรองเหตุการณ์เป็น **เดือน–ปีเริ่มต้น ถึงเดือน–ปีสิ้นสุด** ไม่มีตัวกรองวัน แสดงช่วงสัปดาห์อาทิตย์–เสาร์ที่ครอบคลุม และมีตารางเจาะรายสัปดาห์ของเดือนที่เลือก

คำนวณรายเดือนจากวันเกิดเหตุจริงของ AIID ส่วน EUvsDisinfo จากวันหักล้างจริง ไม่ใช้ปีอย่างเดียว สัปดาห์คร่อมเดือนนับเฉพาะวันที่อยู่ภายในเดือนนั้น ไม่ดึงวันนอกเดือนมารวม ส่วน Freedom มีเพียงรายปีจึงใช้ตัวกรองปีแยก ไม่ประมาณคะแนนรายเดือน/สัปดาห์

รายละเอียดวิธีนับ/คุณภาพอยู่ภายในแต่ละแท็บ AFNC/ACSC/weekly_panel ไม่แสดงเป็นแท็บเพิ่มเติม ไฟล์สะอาดเดิมยังเก็บไว้

**เหตุการณ์ความเสียหายจาก AI และบริบทข้อมูลออนไลน์**

AIID_Excel_Export-20261026.xlsx ชีต Incidents เป็นตารางหลัก วิเคราะห์ระดับเหตุการณ์ ไม่ใช่จำนวนข่าวหรือยอดคดีในไทย

## คำถามหลักและคอลัมน์รองรับ

| คำถาม | คอลัมน์ | กราฟและข้อจำกัด |
|---|---|---|
| 1. เหตุการณ์ AI ที่ถูกบันทึกเปลี่ยนแปลงอย่างไรในแต่ละเดือน? | Incident ID, date | เส้นรายเดือนพร้อมช่วงสัปดาห์ ไม่ใช่เหตุทั้งหมดที่เกิดจริง |
| 2. ความเสี่ยงประเภทใดถูกบันทึกมากที่สุด? | Incident ID, Risk Domain | แท่งอันดับ พร้อมแยกไม่ระบุ เจตนาเป็นรายละเอียดสนับสนุน |
| 3. ข้อมูลเท็จจาก AI มีสัดส่วนเท่าไร และเกิดปัญหาลักษณะใด? | Risk Domain, Intent, title, description | สัดส่วนในกลุ่มที่มีหมวด แนวโน้ม เจตนาและตัวอย่าง |
| 4. EUvsDisinfo บันทึกการหักล้างมากในช่วงใด? | debunk_id, debunk_date | นับรหัสไม่ซ้ำ เส้นรายเดือนและช่วงสัปดาห์ ไม่กล่าวว่าเป็นเหตุการณ์ AI |
| 5. ประเทศที่เลือกมีเสรีภาพระดับใด และเปลี่ยนแปลงอย่างไร? | FOTN: iso3, data_year, total_score, status และองค์ประกอบ | แผนที่ แนวโน้ม และคะแนนองค์ประกอบ ไม่ใช้แทนความปลอดภัย |

## กติกาการกรองและการเชื่อมกราฟ

- เดือน ประเทศ และเจตนาใช้ร่วมกันในส่วน AIID ทั้งสองแท็บ การ์ด กราฟ ตาราง และสรุปคำนวณจาก scope เดียวกัน
- หมวดความเสี่ยงใช้เฉพาะแท็บ 1 ส่วนแท็บ 2 กรอง Misinformation เสมอ โดยสัดส่วนใช้ตัวหารทุกหมวดที่ระบุภายใต้เวลา/ประเทศ/เจตนาที่เลือก ไม่ใช้ตัวหารเฉพาะ Misinformation จนกลายเป็น 100% เสมอ
- คลิกเดือนเพื่อเปลี่ยนช่วงทุกกราฟในส่วน AIID เป็นเดือนนั้น ใช้ปุ่มกลับช่วงก่อนคลิกเพื่อขยายกลับ คลิกแท่งหมวดและเจตนาได้เหมือน dropdown
- EUvsDisinfo ใช้เดือนเดียวกันเฉพาะขอบเขตที่ทับซ้อน แต่ไม่รับประเทศหรือเจตนาของ AIID
- แผนที่ Freedom และกราฟประเทศใช้ประเทศกับปีปลายช่วงเดียวกัน คลิกปีในกราฟคะแนนทำให้แผนที่และคะแนนเปลี่ยนด้วย
- URL เก็บค่าตัวกรองเพื่อกลับมุมมองเดิม ปุ่มดาวน์โหลดส่งออกเฉพาะ AIID ตามตัวกรองของแท็บที่ใช้งาน

## ข้อมูลที่แนะนำสำหรับงานหลัก 3 แหล่ง

1. AIID 20261026: ข้อมูลหลัก ใช้ snapshot เดียวตรึงฉบับ
2. Freedom on the Net: บริบทประเทศและแผนที่คะแนนเสรีภาพ ไม่ใช่แผนที่เหตุการณ์ AI
3. EUvsDisinfo: บริบทการหักล้างข้อมูลบิดเบือน ไม่อ้างว่าทุกรายการเกี่ยวกับ AI

AFNC และ ACSC รวมทั้ง weekly_panel ไม่ใช้ในสามแท็บปัจจุบัน เก็บเพียงไฟล์ที่เตรียมไว้เพื่ออ้างอิง ไม่บังคับใช้ในเรื่องหลัก

## การเชื่อมที่ทำจริง

- AIID ใช้ Incident ID ไม่ซ้ำเป็นคีย์หลัก
- Country Code เก็บค่าต้นฉบับเพิ่มใน Country Code Raw และปรับค่าที่เขียน United States เป็น US เพียงกรณีที่ยืนยันตรงตัว
- สร้าง ai_country_year_context.csv โดยแปลง ISO2 เป็น ISO3 จากรหัส Natural Earth แล้ว left join FOTN ด้วย iso3 + ปีเหตุการณ์ = data_year
- ผลเชื่อมปัจจุบัน: 1,775 แถวเท่าเดิม จับคู่คะแนนได้ 122 เหตุการณ์ ไม่ระบุประเทศ 1,635 เหตุการณ์ อยู่นอกปีคะแนน 7 และไม่มีคะแนนประเทศ–ปีที่ตรงกันอีก 11
- ไม่เติมคะแนนปีใกล้เคียงให้ปีที่ขาด ไม่เติมประเทศให้เหตุการณ์ที่ไม่ระบุ และไม่ใช้กลุ่ม 122 เหตุการณ์แทนภาพรวมโลก
- หน้าแผนที่ใช้ FOTN เต็มชุด ไม่จำกัดเฉพาะประเทศที่จับคู่ AIID ได้
- EUvsDisinfo ไม่มีคีย์ยืนยันตรงกับ AIID จึงใช้เป็นตารางบริบทแยก การอยู่ใน dashboard เดียวกันไม่ถือว่าเป็น incident-level join
- หากเกณฑ์อาจารย์ต้องการให้ทั้ง 3 แหล่ง JOIN กันโดยตรง ข้อมูลเหล่านี้ยังไม่มีคีย์รองรับครบ ไม่ควรอ้างว่าทำได้แล้ว

## การเตรียมข้อมูลเพิ่ม

- FOTN: ตรวจ country-year ไม่ซ้ำ คะแนน 0–100 คะแนนรวมเท่าผลรวมสามด้าน และ report_edition = data_year + 1
- EUvsDisinfo: แปลงวันที่ DD-MM-YYYY ตรวจ ID เดียวมีวันหักล้างตรงกัน และ deduplicate ก่อนนับ
- แนวโน้มคะแนนเสรีภาพภาพรวมใช้ประเทศกลุ่มเดิมที่มีข้อมูลครบทุกปีในช่วงที่เลือก ไม่เปลี่ยนสมาชิกตามปี
- แผนที่ใช้สีเทาสำหรับไม่มีคะแนน ไม่แทนด้วย 0 ประเทศเล็กที่ไม่มี polygon ใน Natural Earth 110m ยังเลือกผ่านเมนูประเทศได้
- ขอบเขตแผนที่มาจาก Natural Earth public domain: https://www.naturalearthdata.com/about/terms-of-use/

## สิ่งที่ยกเลิกจากทิศทางหลักเดิม

- ไม่ใช้จำนวนคดีหรือความเสียหายไทยเป็น KPI หลัก
- ไม่พยายามระบุว่าคดีไทยเกิดจาก AI หรือข่าวใน AFNC
- ไม่ทำแผนที่จำนวนเหตุการณ์ AI เพื่อสรุปความเสี่ยงของแต่ละประเทศ เพราะข้อมูลประเทศมีเพียง 140 จาก 1,775 เหตุการณ์
- ไม่ทำ scatter plot ไม่วิเคราะห์ NLP เพิ่ม ไม่พยากรณ์ และไม่สรุปเหตุและผล
